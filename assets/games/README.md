# Game top-up catalogue assets and UI

Reference: user-supplied Ommnimarket Game Top-Up Dashboard.png (1364 × 1153).

The hero was generated with the built-in image generation tool in stylized-concept mode on 2026-10-25. hero.webp preserves the detailed transparent artwork; hero.avif is optimized for delivery.

reference.png is an unchanged copy of the supplied reference. cover-atlas.avif is a format-compressed copy at the same pixel dimensions. CSS displays only the ten game illustration regions, each 240 × 184 pixels at x = 46, 308, 568, 820, 1080 and y = 462 or 737. Surrounding page layout, titles, filters, search fields, buttons and descriptions are real HTML. The reference is not used as a full-page UI image.

Both delivery assets are embedded in index.html to preserve the existing server/static-file restrictions. No backend, database, authentication or Shopee purchase code was changed.

The existing game subpage had no transaction provider. Each of the ten cards opens the existing Customer Service dialog and pre-fills a question about availability and denominations, without sending the message or creating an order. Search and category filters run locally; no prices, automatic delivery, 24/7 availability or transaction guarantees are invented. Populer is the default curated view containing all ten choices.

Other subpages retain their existing title, package sections, back behavior and visibility. The game mode is a small isolated UI addition. Layout: five columns on desktop, four below 1150px, three below 850px, two on phones. Reduced motion disables hover movement.
