# Branded e-wallet detail illustrations

Reference: user-supplied `Modern DANA Top-Up Dashboard.png`.

Generated on 2026-10-25 with the built-in image generation tool, stylized-concept mode and transparent backgrounds. Files in this directory: dana, gopay, ovo, shopeepay, linkaja and bank, each as a detailed WebP original and an 800-pixel AVIF delivery copy. The AVIF files preserve alpha and are embedded into index.html. No backend static route changes are required. All generated outputs were visually inspected; generated originals remain in the Codex generated_images directory.

Native HTML provides the provider name/logo tile, eight nominal buttons from Rp 10.000 to Rp 1.000.000, selected state, information panel, support actions and back navigation. The detail palette and phone illustration follow the selected provider. Bank Digital was removed from the selectable catalog and detail styling at the user's request on 2026-10-25. Its original illustration/prompt is retained only as an unused source asset.

Prices follow the user's instruction on 2026-10-25: nominals Rp 10.000–50.000 have a Rp 500 markup, Rp 100.000–300.000 have a Rp 2.000 markup, and Rp 500.000–1.000.000 have a Rp 5.000 markup, consistently across all five active providers. This is presentation pricing; no backend payment integration, automatic balance delivery or QRIS flow has been added. The chosen provider, nominal and displayed price are sent only as an unsent draft to the existing Customer Service form after the customer explicitly chooses the inquiry button. Existing cart, filters, login, admin, backend, database and Shopee logic are retained. Detail enhancement failure falls back to the original support inquiry. Back returns to the filtered list and restores focus/scroll. Escape defers to any open modal. Returning from another subpage resets detail mode.

Four amount columns on desktop become two on smaller screens. Artwork is kept separate from text on narrow devices. Animations use opacity/transform and respect reduced motion.
